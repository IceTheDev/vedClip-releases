Instant replay clipping for Windows. Press a hotkey, keep the moment.

**[Download the latest version](https://github.com/IceTheDev/vedClip-releases/releases/latest)**: run `vedClip-win-Setup.exe`. After that, vedClip updates itself.

> vedClip is in beta. Thank you for helping test it.

vedClip is an instant-replay clipper for Windows. It keeps the last minute or two of your game or screen in memory, and when you press a key it saves that moment as a clip. Then you can trim it, mix the audio tracks, add captions, make a vertical version for TikTok, Shorts or Reels, and drag it into Discord.
